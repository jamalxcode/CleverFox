FAQ
What is the difference between standard cloud servers and GPU-powered cloud servers?
The main difference between standard cloud servers and GPU-powered dedicated servers is the presence of GPUs or GPU accelerators.
In cloud computing, GPUs are integrated into cloud servers to provide enhanced computational power for various applications. They are particularly effective at handling tasks that can be broken down into many smaller, parallel operations, such as graphical design tasks, scientific research computing, and machine learning.
What operating systems are available for virtual GPU instances? Can I use my own OS?
To create a cloud GPU server, the control panel offers pre-configured images of Ubuntu, CentOS, Debian, Fedora, Fedora CoreOS, Windows, Alma Linux, Astra Linux, Rocky Linux, and Oracle Linux with prepared working environments and optimized settings.
If none of the images are suitable, you can use your own image in the control panel.
How do I pay for cloud-based graphics card (GPU) rental?
You can pay for your GPU server rental in your local currency or with your bonus credits.
To do this, you need to top up your account balance in the control panel. The final cost will be automatically deducted based on resource consumption every hour — on a pay-as-you-go model.
For detailed payment instructions and information, please refer to our documentation.
What tasks are GPU server rentals suitable for?
Rental of a cloud-based GPU server is ideal for computationally demanding tasks:
— Various machine learning tasks, including deep learning, neural networks, speech recognition, and big data processing.
— AI training.
— Graphics work: rendering, 3D modeling, working with various graphical models and other resource-intensive tasks.
— Complex data analysis.
— High-performance computing (HPC).
— Scientific modeling and minimizing CUDA computation time.
— Rapid project deployment, including virtual desktop infrastructure (VDI) setup.
Where will the rented server be located?
Servercore is an international IT infrastructure provider specializing in cloud computing, with a local presence in Uzbekistan, Kazakhstan, and Kenya.
The location of your virtual machine depends on the cloud-based GPU server configuration you choose. More details about our data centers, Tier certifications, and regions of presence is available in our documentation .
How is data security ensured on the servers?
To secure data on our servers, we create RAID arrays for local disks and implement triple data replication for network disks. For additional protection, we recommend setting up regular backups. All of our cloud servers come with basic DDoS attack protection. Furthermore, our data centers comply with global and local data security standards, including PCI DSS.
I’m unsure how to choose a cloud GPU server configuration for my business. What should I do?
Reach out to our technical support team. Make a specific request to hello@servercore.com or create a ticket in the control panel. We will help you select a server with suitable disk and memory capacity, and we will respond within one business day.
