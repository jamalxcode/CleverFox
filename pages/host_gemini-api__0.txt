Welcome to Gemini API
Interactions API
Go from a quick prompt to production apps and agents with the Gemini API. Tackle complex coding and multimodal reasoning with Gemini, score calibrated decisions with the Decisions API, or hand multi-step work to a managed agent. Stream voice and video with the Live API, or generate images with Nano Banana, video with Gemini Omni, and music with Lyria.

# Search live docs with the MCP server
npx add-mcp "https://gemini-api-docs-mcp.dev"

agy plugin install https://github.com/google-gemini/gemini-skills
# Let your agent call the API from the terminal
curl -fsSL https://raw.githubusercontent.com/google-gemini/gemini-api-cli/main/scripts/install.sh | bash

Interactions API
link
The Interactions API has become our default interface as of June 2026 and is the best way to build with Gemini models and agents going forward. If you're starting a new project, you should use the Interactions API. While it remains supported, the generateContent API is now considered legacy.
