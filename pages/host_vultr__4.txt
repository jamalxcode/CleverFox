Key Terms
CUDA Cores : Processing units in NVIDIA GPUs that work with the NVIDIA CUDA programming model. CUDA cores handle parallel processing and accelerate computing tasks focused on graphics rendering. They often use a Single Instruction, Multiple Data (SIMD) architecture that executes a single instruction on multiple data elements simultaneously, which results in high throughput for parallel computing.
Stream Processors : Core computational units in AMD GPUs that handle parallel processing tasks such as graphics rendering, general-purpose computation, and AI workloads. Stream processors also use a SIMD architecture that executes a single instruction across multiple data points simultaneously.
Tensor Cores : Specialized hardware components in NVIDIA GPUs that accelerate the matrix-based computations common in deep learning and artificial intelligence workloads. Tensor Cores use mixed-precision computing for neural network training and inference. They perform some parts of a calculation at higher precision and the rest at half precision, and they use error correction and accumulation to keep the results accurate.
Matrix Cores : Specialized hardware units in AMD Instinct™ GPUs that accelerate the matrix-based computations central to artificial intelligence (AI) and high-performance computing (HPC). Matrix Cores use mixed-precision arithmetic and data types such as FP16, BF16, and INT8 to accelerate matrix multiplication and similar operations.
TFLOPS : Tera floating-point operations per second (TeraFLOPS), a unit that measures system performance. A floating-point operation is a mathematical calculation that uses numbers with decimal points. TFLOPS is a useful indicator for comparing the capabilities of different hardware components, and HPC applications such as simulations rely heavily on it.
GPU Briefs
NVIDIA A100 Tensor Core - PCIe : Vultr Bare Metal GPU, powered by the NVIDIA A100 Tensor Core in PCIe format, suits tasks such as AI training and deep learning. This version connects through the PCIe interface, which makes it compatible with many server setups. Its processing capabilities and high memory bandwidth help you manage large datasets and complex models on scalable infrastructure. Learn more about Vultr Bare Metal GPU NVIDIA A100 .
NVIDIA A100 Tensor Core - SXM : Vultr Bare Metal GPU, powered by the NVIDIA A100 Tensor Core in SXM format, is designed for AI and data science workloads. This configuration provides better power delivery and thermal management, which improves performance. Use it to train large neural networks and run extensive computational tasks. Learn more about Vultr Bare Metal GPU NVIDIA A100 .
NVIDIA L40S : Vultr Bare Metal GPU, powered by the NVIDIA L40S, is built for graphics and AI applications such as 3D rendering, AI inference, and video processing. Its high memory capacity and efficient processing help you render detailed graphics and handle complex data tasks. Learn more about Vultr Bare Metal GPU NVIDIA L40S .
NVIDIA H100 Tensor Core : Vultr Bare Metal GPU, powered by the NVIDIA H100, is designed for AI workloads, including large language model (LLM) training and inference. Its architecture and Tensor Cores provide higher performance and efficiency for demanding applications. Use it for research and complex tasks that require significant computational resources. Learn more about Vultr Bare Metal GPU NVIDIA H100 .
NVIDIA GH200 Superchip : Vultr Bare Metal GPU, powered by the NVIDIA GH200 Superchip, combines multiple GPU components for AI and HPC workloads. This design improves scalability and efficiency for complex tasks that demand substantial computing power, such as large-scale AI deployments, scientific simulations, and data analytics. Learn more about Vultr Bare Metal GPU NVIDIA GH200 Superchip .
AMD Instinct™ MI300X : Vultr Bare Metal GPU, powered by the AMD Instinct™ MI300X, is designed for AI and HPC applications. Its memory bandwidth and support for large-scale models suit training and inference for AI and deep learning tasks. Use it for scalable complex data processing and scientific simulations. Learn more about Vultr Bare Metal GPU AMD Instinct™ MI300X .
AMD Instinct™ MI355X : Vultr Bare Metal GPU, powered by the AMD Instinct™ MI355X, is built for AI, deep learning, and HPC workloads. It uses the CDNA 4 architecture and provides 288 GB of High Bandwidth Memory 3e (HBM3e) per GPU, with FP8 and FP4 compute for training and inference of very large models. Its design emphasizes memory bandwidth and compute efficiency for generative AI, LLMs, and large-scale scientific simulations. Learn more about Vultr Bare Metal GPU AMD Instinct™ MI355X .
NVIDIA HGX B200 : Vultr Bare Metal GPU, powered by the NVIDIA HGX B200, uses the NVIDIA Blackwell architecture for AI acceleration. The B200 is designed for large-scale AI workloads, including generative AI, LLM training, and scientific computing, and supports FP8 and FP4 precision. With up to 192 GB of HBM3e memory per GPU and high memory bandwidth, it supports training and deployment of large models. Its NVLink architecture supports multi-GPU scaling for enterprise AI workloads. Use it for research, AI inference at scale, and data-intensive computing. Learn more about Vultr Bare Metal GPU NVIDIA HGX B200 .
