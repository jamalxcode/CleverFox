FAQs Inference FAQs
What is Hyperbolic Flux? Flux is Hyperbolic’s inference service for running open AI models through one OpenAI-compatible API. Build applications, stream responses, and manage token-based usage without provisioning GPUs or operating model-serving infrastructure.
Which AI models can I access? The Flux model catalog includes GLM-5.3-Flash, DeepSeek V4.1 Flash, Kimi K3, MiniMax M3, MiMo-V2.6-Flash, and other models. Check the current catalog for available models, pricing, and supported parameters.
Is Hyperbolic’s inference API compatible with the OpenAI SDK? Yes. Flux supports OpenAI-compatible Chat Completions and streaming responses. Configure the OpenAI SDK with your Hyperbolic API key, set the base URL to https://api.hyperbolic.ai/inference/v1, and choose a supported model ID. Model-specific parameters and reasoning behavior may differ.
How does inference pricing work? Flux uses token-based pricing, with rates set for each model. Input, cached-input, and output tokens may have different rates where supported. Reasoning tokens are billed as output tokens. Usage is deducted from your prepaid Hyperbolic balance.
How do I get started with Hyperbolic inference? Use a Pro account or an Organization with prepaid credits, create an API key in the Hyperbolic console, and connect through the OpenAI SDK or REST API. Organization API keys use the organization’s balance. Requests are declined when the balance runs out.
Does Flux support streaming responses? Yes. Flux streams Chat Completions through server-sent events, allowing applications to display responses incrementally. Reasoning models may generate reasoning before final-answer text appears, and reasoning response formats vary by model.
Do I need to manage GPUs to use Flux? No. Hyperbolic manages the model-serving infrastructure behind the API. You select a supported model and send requests, without configuring GPU instances, installing serving software, or maintaining model deployments.
What is the difference between an inference API and dedicated GPU compute? An inference API provides access to supported models with token-based billing. Dedicated GPU compute gives you control over the deployment environment, model weights, and serving configuration. The right choice depends on your customization needs, traffic, and GPU utilization.
How does Flux use Forge? Flux is built on Forge, Hyperbolic’s infrastructure orchestration platform. Forge integrates compute across providers and clusters, supports virtualization, and dynamically allocates GPU capacity across workloads.
Can I use my existing Hyperbolic API key? Flux requires an API key that starts with sk_live_. If your key uses the older format, create a new one in the Hyperbolic console. Applications using the earlier inference API also need the new base URL and a supported model ID.
