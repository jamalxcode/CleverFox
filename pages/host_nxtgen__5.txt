Frequently Asked Questions
What is SpeedCloud Supreme?
+
SpeedCloud Supreme is NxtGen’s fully managed, sovereign private cloud platform built on Red Hat OpenShift, delivering enterprise-grade performance, AI-ready infrastructure, integrated security, and predictable costs for regulated and performance-intensive workloads.
Does it support AI/ML workloads?
+
Yes. Supreme is optimized for AI/ML with GPU-backed infrastructure as well as on CPU, high-memory configurations, low-latency storage, and scalable compute designed for training, inference, analytics, and data-intensive processing.
How secure is the platform?
+
SpeedCloud Supreme features encryption at rest and in transit, HSM-based key management, NGFW, WAF, PAM, 24×7 SOC monitoring, and compliance-aligned controls for regulated industries. However, these are add-ons which is not part of the default SKUs.
Can it be deployed on-prem or hosted?
+
SpeedCloud Supreme offers flexible deployment-either on-premises for full control and ownership, or fully hosted in NxtGen data centers with enterprise-grade SLAs and managed operations.
How is it different from a traditional private cloud?
+
Unlike traditional private clouds, Supreme combines high-throughput performance, sovereign architecture, integrated security stack, and 24×7 managed operations, all without expensive virtualization licensing or hyperscaler cost unpredictability.
Can I run Kubernetes and OpenShift?
+
Absolutely. Supreme supports managed Kubernetes clusters and Red Hat OpenShift, enabling containerized, cloud-native applications with orchestration, auto-scaling, and DevOps-ready deployment pipelines.
Is cloud recovery truly free?
+
Cloud recovery under SpeedCloud Supreme is available as an add-on service. While the platform is DR-ready with built-in architecture support, replication, storage, and failover execution incur additional charges based on configuration and usage.
