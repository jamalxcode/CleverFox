BOTNOI API
Add AI voices to your product with one API call
Send text, get back a link to the audio. Works from your own code, from n8n and from AI agents. Everything needed to make the first call is on this page.
BASE URL
https://api-voice.botnoi.ai
AUTHENTICATION
Header botnoi-token: YOUR_API_KEY. No "Bearer" prefix.
LIMIT
500 characters for V2, 500 characters for V1, 1000 characters for V4, 200 for Voice Design, per request.
BILLING
Points per letter of text. Letters are counted without spaces, delay{x} pauses and [sound tags]. Each request is rounded up to a whole point, so a paid call costs at least 1 point. Subscribers (an active Trial+, Starter, Pro, Elite or Premium plan; NoAds alone does not count) pay half.
V2
Premium voices
POST /openapi/v1/generate_audio_v2
0.2 points per letter (0.1 for subscribers), rounded up per request. Speaker list: GET /openapi/v1/get_speaker_data_v2
V1
Classic voices
POST /openapi/v1/generate_audio
0.1 points per letter (0.05 for subscribers), rounded up per request. Speaker list: GET /openapi/v1/get_speaker_data
V4
Expressive voices with sound tags
POST /openapi/v1/generate_audio_v4
0.2 points per letter (0.1 for subscribers), rounded up per request. A line of only sound tags: 0.6 per tag (0.3 for subscribers). Voice Design and voice clones cost the same as V4. Speaker list: GET /openapi/v1/get_speaker_data_v4
Use V2 for the most natural voices. Use V1 for the widest choice of voices and languages, or the lowest cost.

curl -X POST 'https://api-voice.botnoi.ai/openapi/v1/generate_audio_v2' \
-H 'botnoi-token: YOUR_API_KEY' \
-H 'Content-Type: application/json' \
-d '{
"text": "สวัสดีครับ",
"speaker": "8",
"volume": 1,
"speed": 1,
"type_media": "mp3",
"save_file": "True",
"language": "th"
}'
RESPONSE 200
{
"text": "สวัสดีครับ",
"audio_url": "https://.../example.mp3",
"point": 6534,
"user_monthly_point": 0
}
Request body
FIELD TYPE REQUIRED NOTES
text string yes Text to speak. Up to 1000 characters per request for V4 (and voice clones), 500 for V1 and V2, 200 for Voice Design. Must be written in the language given in language.
speaker string yes Speaker ID, as a string. V1 and V2 have separate ID lists.
language string yes Language code of the text, for example th or en.
type_media string yes Output format: mp3 or wav.
speed number no Speaking speed, 0.5 to 2.0. Default 1.
volume number no V1 and V2: 0.1 to 2.0, 1 is normal. V4: a percentage, 100 is normal (default 100).
save_file string no Send "True" to get a hosted audio_url back.
split_english boolean no V4 only. true voices long English names (2+ words or 10+ letters) on their own and joins them back into the Thai line. Default false.
trim_breath boolean no V4 only. true cuts the breath before the first word and after the last. Default false.

Questions people ask
What is Botnoi Voice?
Botnoi Voice is a Thai AI media platform. It started with text to speech, with more than 400 voices in over 20 languages, and now also generates images, video and talking avatars, runs voice bots for phone calls, and offers tools for ad scripts, slide narration and subtitles.
How do I turn text into speech?
Type or paste your text, choose a language and a voice, then press Generate. In Voice Studio every line of a script can have its own voice, speed and volume, and you can download the result when you are happy with it.
Can I try it before paying?
Yes. You can try the voices on this page 3 times a day without an account, and new users can generate voices for free after signing up.
How does pricing work?
You pay with points, and points are used for each letter you turn into speech (V1 1 point a letter, V2 and V4 2 points; spaces are not counted). Top up from 99 baht, or subscribe from an average of 200 baht a month for monthly points, and subscribers pay half. Current prices are on the pricing page.
Which languages and how many voices are there?
More than 400 voices in over 20 languages: Thai and every ASEAN language, plus English, Chinese, Japanese, Korean, Hindi, Arabic and major European languages. Voices differ in age, tone and speaking style.
Can it make video and images too?
Yes. The media studio generates images with SeeDream, video with SeeDance and talking avatars with OmniHuman, and Gen Skript can turn a slide deck into a narrated video. They use the same points as voice generation.
Can I use it for teaching materials?
Yes. Gen Skript takes your slides, a PDF or images and writes a narration script for each page, which you can then voice. Many teachers use it to make lesson videos and listening materials.
Is there an API?
Yes. A REST API with two versions: V2 for the most natural voices and V1 for the widest choice. You send text and a speaker ID and receive a link to the audio. The Developers section on this page has everything needed for the first call.
Where else can I use Botnoi voices?
Botnoi Voice is available as an app inside Canva, as a verified node on n8n, on AWS Marketplace and as a mobile app.
