# CleverFox mascot: source files

- `fox-original.webp`: the original mascot artwork, as provided by the owner (1254 × 1254, white background).
- `fox-cutout.png`: the same fox with the background removed (transparent), full size. Made by flood-filling the white background from the edges, so the white fur inside the outline is kept.

The site uses smaller copies made from these: `../fox.webp` (mascot, 400 px tall), `../fox-logo.webp` (head, 96 px), `../favicon-32.png`, `../apple-touch-icon.png` and `../og.jpg` (link-preview image, 1200 × 630). Regenerate them from `fox-cutout.png` if the artwork changes. These source files are not deployed with the site.
