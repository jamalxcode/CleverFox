📖 Glossary

The words CleverFox uses, in plain language.

Model

The "brain" behind an AI app: a large file trained to write, talk, code, see or make pictures. Apps like ChatGPT use models behind the scenes. Some models can be downloaded and run on your own computer or phone.

Runs locally / offline

The model runs on your own device. Nothing you type leaves it, it works without internet once downloaded, and it's free to use. It needs enough memory (see below).

Memory (RAM or graphics card memory)

How much the device can hold at once. A model must fit in memory to run. On Windows and Linux, check RAM, or the graphics card's memory (VRAM) if you have one. On a Mac, the memory is shared, so the full amount counts. CleverFox's "needs ~X GB" is an estimate from the file size or the model's size; "recommended" leaves room for the rest of your computer.

4-bit, 8-bit, 16-bit (quantization)

Ways of shrinking a model. A 4-bit copy is about a quarter of the size of the full 16-bit one and runs on smaller devices, with a small loss in quality. Most people running models at home use 4-bit.

Parameters (7B, 30B…)

The size of a model, in billions of numbers ("B"). Bigger usually means smarter but needs more memory. Size isn't the same as memory needed: a 7B model at 4-bit needs about 5 GB.

Tokens

The pieces of text AI services count and charge for. One token is about three quarters of an English word, so 1 million tokens is roughly 750,000 words, several long books. Online prices are "per million tokens", usually one price for what you send (input) and another for what the AI writes (output).

API and API provider

A way for programs and developer tools to use a model over the internet, paying per use. An API provider runs models on its own servers so you don't need a powerful computer. "Use it online" on CleverFox lists them.

GGUF, MLX, ONNX

File formats for running models on your own device. GGUF works with Ollama, LM Studio, Jan and llama.cpp on Windows, Mac and Linux. MLX is for Apple Silicon Macs. ONNX runs in many apps and on phones.

Ollama, LM Studio, Jan

Free programs that download and run models on your computer. Ollama uses one command (CleverFox shows it on each model); LM Studio and Jan are point and click.

Open weights, open source, license

"Open weights" means you can download the model; it doesn't always mean you can use it for anything. The license says what's allowed, for example whether commercial use is permitted. Open source usually means the code and training details are open too.

Benchmarks (ECI, AA index)

Tests of how capable a model is. CleverFox shows independent ones: the Epoch Capabilities Index (ECI) from Epoch AI and the Artificial Analysis index. Higher is better. A company's own scores are labeled "self-reported" because no one else checked them.

Free, free tier, trial

Free: no payment for normal use. Free tier: a free plan with limits, and paid plans for more. Trial: free for a short time, then paid.

Pay without a card

Ways to pay that don't need a Visa or Mastercard: mobile money (such as M-Pesa), UPI, Pix, PayPal, bank transfer, crypto, app store billing, gift cards or your phone bill. CleverFox lists only official payment routes.

Uncensored / abliterated

Copies of models changed by someone other than the maker to refuse fewer requests. They can produce harmful or false content; use them with care.

Verified, not yet verified

Verified means the facts were read on the official page, by hand or by CleverFox's automatic page check. Not yet verified means they came from search results and still need checking. Every fact links to where it came from.
